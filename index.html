      How this works

      Streak: days in a row with at least one test passed.

      Learned: quotes you got right for the first time. Reviewed: quotes you got right again.

      Short-term quotes you have got right, but only recently. Long-term quotes you have recalled correctly after waiting several days.

      Each quote: you do different tests on it, and it only counts as passed if you get every test right first time.

      When a quote is due, pass a hard test to move it up: hard gaps, hard jumble, first letters, or from memory. Forget it and it drops back a step.

      Review learned lets you go back over anything you have learned. Getting it right early restarts the wait until it is next due.
